Read repository `AGENTS.md`, the relevant engineering report, architecture documentation and the code being discussed.

Generate questions that probe the actual decisions, alternatives, testing evidence and limitations of the work. Store requested question artifacts in `docs/interview-questions/`, linked to the corresponding report.

Distinguish implemented behavior from planned technologies. Do not describe SQL Server, Angular, persistence or AI integrations as implemented unless the repository supports the claim. When answers are requested, ground them in concrete files and tradeoffs rather than generic interview scripts.
