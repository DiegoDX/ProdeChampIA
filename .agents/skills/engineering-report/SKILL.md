---
name: engineering-report
description: Produce a ProdeChamp engineering report from completed changes and actual verification evidence.
---

Read repository `AGENTS.md`, the requested scope, the actual changes and any verification output. Use `docs/engineering-reports/` for reports when an artifact is requested or appropriate.

Record the outcome, files changed, technical decisions, commands executed with actual results, known limitations and generated interview questions. Link related material in `docs/interview-questions/` when present.

Distinguish passed checks, failed checks, checks not run and tests with zero discovery. Do not infer success from a command being issued. Include environment blockers and their practical impact without claiming unavailable behavior was validated.

Keep the report consistent with the final repository state and the approved scope. Do not claim a commit, deployment or integration occurred without evidence.
